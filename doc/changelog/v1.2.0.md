# 墨笺 1.2.0

## 新增

- **笔记本改名同步磁盘目录**：重命名笔记本时先改工作区下的文件夹，再更新笔记本标识，软件内名称与磁盘路径一致，便于在资源管理器中找到附件与资源。
- **笔记树复制 / 粘贴 / 创建副本**：支持在笔记本内复制、粘贴；名称冲突时自动加「副本」后缀。
- **跨笔记本移动**：通过选择器指定目标笔记本或文件夹，完成跨本移动。
- **受控 HTML 子集**：笔记中可使用白名单 `img` / `div` / `span` / `style`（尺寸、颜色等）；预览与 PDF / PNG 导出共用同一语义。规范见 `doc/墨笺-html-子集.md`。
- **导出 WebP**：笔记可导出为 WebP；长图支持连续排版；导出流程补充打开结果、覆盖确认等体验。

## 修复

- **编辑器查找栏**：修复输入查询时选区被反复重选的问题（本地 vendoring `gpui-component` 补丁）。
