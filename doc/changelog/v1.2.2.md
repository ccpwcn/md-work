# 墨笺 1.2.2

## 新增

- **笔记树拖拽排序**：笔记本可在工作区里调整先后；笔记和文件夹可在同一层内调整顺序。顺序记在工作区的 `notebook-order.toml` 和笔记本内的 `order.toml`，整本打包时一并带走。没有这些文件时仍按名称排序。新建笔记本排在已有本子之后。重命名、移入回收站和恢复时，顺序跟着走。
- **导出表格宽度**：可选择表格按内容收缩，或拉满正文宽度、各列均分。

## 优化

- **笔记树**：新建笔记本、笔记或文件夹后，直接在该项上输入名称。
- **笔记树**：文件夹右键可以新建子笔记、子文件夹、同级笔记、同级文件夹。子项的名称框出现在下一层，确认后仍留在该层。
- **窗口**：记住主窗口的大小、位置和是否最大化。下次启动时回到上次所在的显示器；全屏等过渡状态不写入配置。
- **导出面板**：对话框加宽，格式与纸张等选项排在同一行。切换格式时面板高度不变，「取消」不再挨着原先「开始导出」的位置。
- **说明文档**：去掉「笔记读写仍在界面线程」这句与现状不符的说明。

## 修复

- **笔记树**：在某条笔记旁边新建时，名称框有时会先落到本层最底部，再跳回正确的下一行。新建过程中先不刷新文件树，等顺序写完再显示。
- **预览与导出**：连续空行会留下来。段落之间的一个空行仍只表示分段；从第二个空行起，预览和 PDF / 图片按行距留出空白。从预览复制纯文本时不带这些额外空行。
- **导出引用**：块引用在 PDF / 图片里画出与预览一致的左侧竖线。
