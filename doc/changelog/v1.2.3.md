# 墨笺 1.2.3

> 版本：`1.2.3` · Git 标签：`v1.2.3` · 发布日期：2026-11-06

## 新增

- **预览文本选区**：预览模式下可用鼠标拖选正文，选中片段高亮显示，按 `Ctrl+C` 直接复制渲染后的文本；跨标题、代码块、表格等片段按阅读顺序连成一段选区。
- **预览右键复制**：有选区时右键提供「复制」（渲染后的纯文本）与「复制为 Markdown」（按预览块记录的源码行映射回 Markdown；跨图片、表格等无法定位时退化为复制整篇源码）；未选中文本时不弹菜单。工具栏「复制全文」与代码块「复制」按钮保持可用。
- **笔记树剪切 / 粘贴**：笔记与文件夹右键新增「剪切」，再在目标文件夹、条目所在层或笔记本标题上「粘贴」即可移动，也支持跨笔记本；使用应用内剪贴板，剪切后源行半透明显示、成功粘贴一次即清空。源条目已不存在或目标非法（如移入自身子树）时提示「无法粘贴到此位置」。

## 优化

- **图标**：为软件主程序与安装程序专门设计图标；竖版画板改为等比缩放并居中到正方形 ICO 帧，避免拉伸变形；卸载程序改用 NSIS 默认图标。`xtask icon` 按 5 档 / 7 档尺寸生成 ICO，并有像素级回归测试。
- **笔记树拖放**：文件夹行中间一半表示「放入其中」，上下四分之一仍是同级排序；支持把条目拖出文件夹到上一级或笔记本根目录、拖到笔记本标题或末尾空白处追加，以及跨笔记本拖入文件夹；禁止拖入自身、子目录、当前父文件夹或重名目标，拖放落点的顺序会同步写入 `order.toml`。
- **面板滚动条**：笔记树、大纲、搜索、书签、回收站在内容超出可视区时各自显示滚动条，滚动位置互不干扰。
- **多文档标签**：以稳定的文档实体 ID 管理激活、关闭、批量关闭、拖拽重排与状态栏统计；拖拽重排只移动标签实体、不重建编辑器，撤销历史与视图状态得以保留；右键菜单触发器常驻挂载，避免元素 id 路径变化导致预览选区句柄丢失。
- **预览性能**：公式 SVG 合并为一个后台任务、完成后只通知一次；整篇预览只注册一个选区代理，避免大文档预览反复重建元素树和 O(n²) 重绘。

## 修复

- 修复笔记名称太长时覆盖遮挡操作按钮的问题。
- 修复多文档标签切换、关闭前序标签后状态异常的问题（标签下标漂移）。
- 修复编辑 / 预览模式切换是全局状态的问题，现在每个笔记 / 文档各自记住自己的模式。
- 修复笔记本点击名称时先收起又立刻展开的问题。
- 修复移动 / 重命名后仍在保存中的标签会写到旧路径的问题。
