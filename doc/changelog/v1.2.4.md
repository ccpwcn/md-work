# 墨笺 1.2.4

## 新增

- **大纲跟随内容**：编辑与预览时，大纲面板自动高亮当前章节——编辑态跟随光标所在行，预览态跟随视口顶部所在的标题；当前章节变化时大纲自动滚动到该项，手动浏览大纲时不会被每帧打断。
- **大纲跳转**：点击大纲可在当前文档内跳转，不再依赖文档所属笔记本，外部打开的文档同样可用。预览态把标题滚到视口顶部附近；编辑态把光标移到标题行，并把该行对齐到视口上沿。

## 优化

- **笔记预览性能**：把预览正文与选区高亮拆成两层：正文在文档内容与渲染配置不变时整段缓存、跳过重绘与重新排版，只有轻量的选区覆盖层随选择变化重绘。拖选、滚动、缩放窗口以及图片 / 公式异步加载后，不会累积旧的选区片段，打开和拖选大文档明显更流畅。
- **笔记预览·滚动条**：预览滚动区改用独立的滚动条覆盖层，滚动条随内容长度自动出现，不再挤占正文宽度。
- **笔记预览·表格**：数据行增加隔行底色，鼠标悬停时整行高亮，长表格更容易横向对行。

## 修复

- 修复鼠标拖动得到选区的过程中，选区变化跟不上鼠标移动动作的问题。
- 修复预览模式下，行内代码的头尾的倒引号仍然存在的问题。
- 修复点击大纲时，内容区域滚动条不能正确导航跳转的问题。
- 修复编辑态点击大纲时，先跳到反方向再抖动一下的问题；现在向上和向下跳转都只滚动一次，并统一停在标题行上沿。
- 修复预览选区在页面滚动后仍按旧位置投影的问题；现在选区端点跟随文字移动，滚动不会让选区落到别的行或自行变大变小。
- 修复文字块之外的空白被当成可选文本的问题；在空白处按下不再选中整个视口。
- 修复快速连续拖选时上一次的高亮残留在屏幕上的问题；新的一次按下会立即清除旧选区。

## 其他

- **发版流程**：GitHub 只在 `main` 上发版，并要求 `vX.Y.Z` 标签已进入 `main` 历史；`dev` 的推送（无论是否带标签）只构建与测试，不再发版。发版说明固定取与标签同名的 `doc/changelog/vX.Y.Z.md`；标签与 `Cargo.toml` 版本不一致时拒绝发版，squash / rebase 合并后需在 `main` 重新打标签。CI 工作流与 `doc/ci.md` 已同步更新。
- **开发约定**：补充 Agent 的 XERJ 检索与索引约定；新增预览选区拖选、滚动保持、空白命中、大纲跳转对齐与标题位置不累积等回归测试。
