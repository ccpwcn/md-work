# 墨笺 1.2.5

## 新增

- **完整可用的 MCP 服务与授权体系**：AI Agent 现在可以访问墨笺的工作区。服务提供 stdio 与 Streamable HTTP（仅监听 `127.0.0.1`，默认端口 `11026`）两种接入方式，共 14 个工具，覆盖笔记本与笔记列举、读取、大纲、书签、搜索、写入、追加、移动、删除、导出，并提供笔记 resources；HTTP 每个请求都需 Bearer 令牌，服务默认关闭，可在设置中启停、修改端口并一键复制 `mcpServers` 客户端配置。
- **两层权限取交集**：令牌侧可授予 `read` / `write` / `search` / `delete` / `delete:permanent` / `export` / `admin` 七种 scope，并限定可访问笔记本与笔记路径白 / 黑名单；笔记侧按「笔记本 + 笔记路径」设置 `隐藏 < 只读 < 修改 < 删除` 四级授权，支持父子联动与单独授权，重命名 / 移动时权限跟着迁移。默认全部隐藏，新建内容也需重新授权；越权调用返回明确的 `FORBIDDEN` 等错误码，删除默认进回收站，GUI 有未保存修改时拒写，写入可用 `sha256` 防并发覆盖。
- **MCP 设置面板与审计**：新增「服务 / 令牌 / 权限 / 审计」四页，可按笔记本树逐节点授权、查看聚合状态与「受上级限制」提示，令牌可新建、轮换、吊销、删除并二次确认，明文令牌只显示一次；审计页记录工具调用、令牌、路径、结果与耗时，不记录笔记正文。令牌库只存哈希并用 DPAPI 加密，权限树以 HMAC 签名与独立密钥保护，外部手改即按「全部隐藏」失效关闭并给出篡改告警。
- **内置官方说明文档**：随包提供本版本更新说明与 MCP 使用说明，并在编译期嵌入程序内置权威副本。升级后首次启动自动以只读预览打开更新说明，关闭后本版本不再提醒；设置 → MCP 页可打开 MCP 说明，直接打开安装目录里的文档也会识别为官方文档。官方标签强制预览 + 只读，禁止编辑与保存；磁盘副本与内置正文做 SHA-256 比对，被改动或缺失时提示并仍显示内置权威内容，不写回磁盘。

## 优化

- **设置面板重排**：改为居中弹窗，左侧导航分「通用 / 集成服务」两组，右侧卡片式内容页配标题与说明提示，底部显示版本与许可证；统一卡片、分段控件、加载占位与状态文案，工作区、外观、面板、Windows、图床、MCP 六页的入口与状态更直观。
- **图床设置**：改为「本地 / PicGo / HTTP」三段式切换，按模式只显示相关字段，底部固定保存按钮与成功 / 错误反馈。
- **字体与自动保存即时生效**：新增「应用字体」按钮，关闭设置面板时也会应用并保存界面字体、笔记字体与字号；自动保存开关切换后立即同步到所有已打开的文档。
- **MCP 设置交互**：服务开关切换即刻启停，不再需要额外点「应用」；权限与令牌的加密签名写盘移到后台线程，笔记较多时设置面板不再卡顿；启动失败、端口占用等给出具体原因。

## 修复

- 修复文档预览模式下鼠标指针停在代码块上时滚轮可能不起作用的问题：代码块的横向滚动层会抢走垂直滚轮，现在滚轮直接传给预览页面，横向仍可用滚动条、触控板横滑或 `Shift` + 滚轮，并补了回归用例。
- 修复图床设置保存后对话框退回「加载中」、必须关闭整个设置窗口重开才能继续编辑的问题。

## 其他

- **随包文档与打包校验**：`xtask package` 按 `Cargo.toml` 版本定位 `doc/changelog/vX.Y.Z.md`，缺更新说明或 MCP 说明、便携目录子目录漏包都会直接中止；zip 中的官方文档设只读位；`scripts/build-installer.ps1` 串起测试、图标、打包与安装包，并校验安装包与便携包里的 `changelog.md` / `mcp.md`。
- **安装包与验收**：新增开始菜单「墨笺」「卸载 墨笺」与桌面快捷方式、HKCU 卸载信息；升级时先清旧文档只读属性再覆盖，卸载时清理随包文档与卸载项，笔记、设置与文件关联保留。新增 MCP 权限矩阵、令牌、会话隔离、篡改失效关闭等集成测试，以及随包文档只读、首次启动自动打开、篡改提示等手工验收项。
