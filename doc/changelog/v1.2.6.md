# 墨笺 1.2.6

## 优化

- **状态栏信息分组**：把同类状态排成一组——当前笔记本 / 文件来源、光标位置、全文与选区统计、文件编码与换行符、保存状态 / 编辑或预览模式 / 异常提示 / 自动保存、MCP 服务状态——组间用取状态栏边框色的细竖线分隔，亮 / 暗主题下层次一致又不抢文字；间距收紧、各组不被压缩，未打开文档时也保持同样的分组，MCP 状态始终靠右且分隔线紧贴其左侧。

## 修复

- 修复设置页「工作区」介绍与图床「本地」模式提示等长说明文字被挤压、显示不完整的问题：卡片副标题与次要说明文字解除 flex 项的最小内容宽度约束，按可用宽度换行，长文案可完整显示。
- 修复预览图片在窗口或面板变窄时仍按原图像素高度占位、图片下方空出一大片随宽度变化的留白的问题：图片盒子宽度改为相对父级宽度表达、原图宽度只作上限，高度按实际可用宽度与原图宽高比推导；百分比高度按文档约定相对内容区宽度换算，不再相对视口高度；显式指定像素宽高时保持固定盒子，给定像素高度时按宽高比限制宽度以避免 letterbox 空白；SVG / 加载中等取不到自然尺寸时使用固定占位高度。
- 修复列表项下的围栏代码块、图片按编辑习惯只缩进两个空格时，被 CommonMark 解析成顶层块、把列表拆成几段且缩进与同级内容不一致的问题：解析前把这些续行补齐到列表内容列（`1. ` 为第 3 列、`- ` 为第 2 列），预览与 Typst 导出都保持同一个列表项；只补行首空格，行数、源码行号与代码块内容不变，大纲跳转不受影响，顶格围栏仍按标准结束列表。
- 修复新建笔记输入带点的名称（如「v1.2 计划」「第1.章」）后回车改名没有任何效果的问题：笔记路径只在显式以 `.md` / `.markdown` 结尾时视为带扩展名，其余一律补 `.md`，不再把名称中间的点误判成扩展名并拒绝写入。
- 修复编辑源码时输入 `_` / `*` 等强调标记，整段文字随 tree-sitter 节点反复出现 / 消失在斜体与正体之间跳动的问题：内置亮 / 暗语法主题对 `emphasis`、`link_uri` 不再使用斜体。

## 其他

- **回归测试**：新增图片盒子高度随可用宽度变化（700px 与 1400px 实测）、列表续行补齐与 Typst 导出列表内代码块、笔记名含点的归一化与重命名、内置语法主题不给源码加斜体等用例，并覆盖 CRLF 行尾与行号保持、顶格围栏和已正确缩进的列表不被改写。
