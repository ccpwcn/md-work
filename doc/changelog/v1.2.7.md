# 墨笺 1.2.7

## 新增

- **《欢迎使用墨笺》入门文档**：随包提供一篇面向用户的简短入门说明，只讲怎么开始写、怎么把笔记找回来、去哪调整设置，篇幅控制在一块笔记本小屏幕的三分之二以内，不再罗列技术实现。它与更新说明、MCP 说明同属官方权威文档：编译期嵌入程序内置正文，磁盘副本只做 SHA-256 校验，强制只读预览、禁止编辑与保存，改动或缺失时仍显示内置权威内容。全新安装或升级到新版本后首次启动自动打开一次（按版本记录，本版本不再重复提醒）；设置窗口左下角「欢迎文档」可随时重新打开。原先自动写入工作区的可编辑示例笔记不再生成，新建工作区保持干净。
- **图床 · 本地 assets 未引用图片一键清理**：设置 → 图床新增清理卡片，打开页面即在后台扫描，列出可清理的文件数与占用空间，支持重新扫描。引用判定覆盖工作区内所有 Markdown 的图片引用，包括相对路径、HTML `<img>`、URL 编码文件名与跨笔记本引用，对空格 / 括号 / 中文等特殊文件名额外做全文兜底，宁可少删也不误删；只统计图片扩展名，assets 里的其他文件不受影响。点击「一键清理」先弹出二次确认「被删除清理的资源将无法恢复，是否继续？」，确认时再重新扫描一次才删除，避免扫描到确认之间新引用的图片被误删。扫描与删除均在后台线程执行，过期任务的回调会被丢弃，大工作区也不会卡住界面。
- **字体设置 · 选择本机已安装字体**：界面字体与笔记字体各新增「选择字体」入口，列出本机全部已安装字体并支持按名称搜索。字体在后台线程异步枚举一次并缓存，列表按可见行数虚拟渲染，系统只装了几款或装了上千款字体都不会拖慢设置窗口；没有匹配结果或未读到字体时给出对应提示，仍可手动输入字体名。列表首项为「系统默认（留空）」，与原有「留空即使用系统默认字体」的规则保持一致；新增「恢复默认字体」，一键把两个字体名清空并把界面 / 笔记字号还原为 15 / 16。
- **笔记树与页签右键「复制路径」「打开所在文件夹」**：右键笔记或文件夹可把绝对路径写入系统剪贴板，或在文件管理器中定位；Windows 用 `explorer /select` 选中文件，文件夹直接打开，官方只读文档不提供这两项。已打开笔记的页签右键菜单同样可用。
- **页签悬浮显示完整名称**：鼠标停在已打开笔记的页签上时显示完整文档名称（含笔记本内相对路径与扩展名）及绝对路径，不再受页签宽度截断影响。

## 优化

- **打开笔记即可直接输入**：从笔记树点开笔记、切换页签，或异步读盘完成后，编辑区自动获得输入焦点，不必再点一下输入区域才能打字；仅在默认编辑态生效，预览态、官方只读文档、有对话框打开，以及笔记树里正在输入笔记 / 笔记本名称时都不抢焦点。新建笔记先把焦点留在树上的起名输入框，回车提交名称后才交给编辑区，不会出现刚新建就跳到右边、名称输入框失焦直接提交默认名的情况。

## 修复

- 修复预览状态下各级标题字号看起来完全一样、只有导出后才能区分的问题：GPUI 的文本 run 不携带 `font_size`，字号只从窗口当前文本样式读取，导致标题里设置的倍率从未生效，六级标题都按正文字号渲染、只剩粗体差别。现在标题容器显式设置字号，h1~h6 按严格递减的倍率取值并配分级上下留白；大纲锚点、选区覆盖层与正文缓存结构保持不变，预览选区、大纲跳转、代码块滚轮、图片缩放等既有行为不受影响。

## 其他

- **随包文档与打包校验**：`xtask` 的官方文档清单与 zip 只读位、NSIS 的安装 / 升级 / 卸载、`scripts/build-installer.ps1` 的产物校验同步扩展到三份文档，缺任意一份直接中止打包；`build.rs` 在文档改动时自动重新嵌入。
- **回归测试**：新增 assets 清理的引用覆盖（URL 编码、HTML、特殊字符文件名、跨笔记本引用）、清理后复扫为空、标题字号严格递减等用例；随包文档嵌入、只读位、首次启动自动打开等既有测试扩展到欢迎文档，Windows 验收清单同步补充。
