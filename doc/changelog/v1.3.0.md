# 墨笺 1.3.0

## 新增

- **扩展主题（自定义主题）**：设置 → 外观新增「当前激活的主题」列表，内置浅色 / 深色 / 跟随系统与扩展主题同列，点选立即生效；窗口、侧栏、编辑器与预览的配色、圆角、阴影和语法高亮一并刷新，选中「跟随系统」时仍随系统明暗切换，选中具体主题则固定它自己的明暗。主题是普通 TOML 文件，放在 `~/.config/md-work/themes/`（Windows 为 `%USERPROFILE%\.config\md-work\themes\`，Unix 遵循 `XDG_CONFIG_HOME`），总配置 `theme_extension.toml` 用 `active` 记录当前主题，路径可用 `MDWORK_THEME_HOME` 覆盖。首次使用会读取原有 `theme.toml` 的亮 / 暗 / 跟随系统偏好，生成带中文注释的总配置，旧设置无需手工迁移。主题文件可覆盖窗口与状态栏、侧栏 / 列表 / 页签 / 弹层、按钮与状态色、编辑器与语法高亮等颜色，以及圆角、阴影、字体等。
- **主题工具与热重载**：设置页提供「导入 Zed 主题」「打开主题目录」「重新扫描」「生成示例主题」。选择 Zed 的 `.json` 主题文件（或直接放进扩展目录）即可转换为墨笺 TOML，每个明暗 variant 各生成一个文件且不覆盖已有主题、原 JSON 保留；「生成示例主题」写出带完整注释的模板，重名自动加序号。扩展主题加载策略可选「自动（立即载入）」「仅启动时」「禁用扩展」：自动模式下监听扩展目录与总配置，文件新建、修改、删除或配置被外部编辑都会热重载并给出通知，按内容比对只提示真正变化的文件。单个主题格式错误只把它标为失败、在列表里显示原因，不影响其它主题，也不覆盖已有配色。
- **主题错误回退与兼容**：激活主题载入失败或文件被删时，按「回退内置主题（默认）」「保留上次有效主题」「跟随系统」三种策略处理并提示。颜色只接受标准十六进制写法，圆角、字号、字重、语法样式都做范围校验与归一化；主题缺少语法主题时补默认亮 / 暗主题，`emphasis`、`link_uri` 等 capture 强制不用斜体，避免源码输入 `_` / `*` 时文字抖动。扩展主题只替换同明暗的内置槽位，切回内置或跟随系统即完整恢复默认配色与高亮；与当前组件库主题格式不兼容的文件会明确报错而非静默生效。界面字体、笔记字体与字号仍以原有字体设置为准，主题里的字体只在设置为空时兜底。
- **笔记树标记已收藏笔记**：设置 → 外观新增「在笔记树中标记已收藏笔记」，可选「不显示」「小圆点」（默认）「书签图标」。只标记整篇被收藏的笔记，不含标题书签；选中标记方式后树中固定留出一个槽位，未收藏的行只是留白，名称左边缘仍对齐，标记沿用文件图标的次要色，不与选中、悬停等导航状态争用颜色。树里同时展开多个笔记本时，其余笔记本的收藏状态在后台补齐；收藏 / 取消收藏后即时同步。对应 `runtime.toml` 的 `bookmark_marker`（`none` / `dot` / `bookmark`）。

## 优化

- **MCP 默认无需令牌**：stdio 与只监听 `127.0.0.1` 的 Streamable HTTP 都是本机通道，令牌对限制外部访问作用不大，因此改为默认可选。打开 设置 → MCP 启用服务、复制「客户端接入」片段即可连上，片段里不再带 `Authorization` / `MDWORK_TOKEN` 字段。未携带令牌的连接作为「本地可信身份」处理，拥有全部工具权限与整个工作区，令牌 ACL 与权限树不再作为门禁；`server_status` 的 `token_name` 显示 `local (no token)`，列表、搜索、书签与资源接口返回工作区全量。需要按笔记本 / 笔记限制可见范围时，再打开「MCP 连接必须携带有效令牌」并生成令牌，改用带令牌的片段；切换开关会保存配置并重启本地服务，已连接的客户端需重连。无论策略如何，只要带了令牌就一定校验：有效令牌仍按原 ACL 与权限树限制，错误 / 过期 / 吊销的令牌不会降级为本地身份，HTTP 返回 `401` 并带 `WWW-Authenticate`；强制令牌模式下缺少身份的工具调用返回 `-32001 UNAUTHORIZED`。越权仍是 `-32003 FORBIDDEN`，审计日志仍不记录笔记正文，HTTP 仍只绑定 `127.0.0.1`、端口占用照旧明确报错。
- **令牌策略可用命令行 / 环境变量覆盖**：`md-work-cli mcp serve` 新增互斥的 `--require-token` / `--no-require-token`，环境变量 `MDWORK_REQUIRE_TOKEN` 支持 `1/true/yes/on/required` 与 `0/false/no/off/optional`，非法值直接报错；优先级为命令行参数 > 环境变量 > `runtime.toml` 的 `mcp_require_token` > 默认可选。GUI 托管的 HTTP 子进程显式传递策略参数，避免配置异步保存期间读到旧值；stdio 由客户端直接拉起命令行，令牌策略以 CLI 侧为准，不受「启动本地 MCP 服务」开关控制。服务页的 HTTP / stdio 片段与提示按开关分别给出带令牌和无令牌两版。

## 其他

- **升级须知（权限边界变化）**：旧 `runtime.toml` 没有 `mcp_require_token` 时按默认 `false` 处理，即升级后本机 MCP 连接不再要求令牌，也不再受权限树限制；希望维持 v1.2.7 及以前的强制校验，请在升级后打开 设置 → MCP 的「必须携带令牌」，或在 CLI / 环境变量中显式要求。若 AI 客户端配置里残留旧的 `MDWORK_TOKEN` / `Authorization`，服务端仍会按该令牌的受限 ACL 处理，删除这些字段才会走本地可信身份。权限树本身没有移除，带令牌连接与防篡改检查照旧。
- **配置与文档**：`runtime.toml` 新增 `bookmark_marker` 与 `mcp_require_token` 两项，非法值回退默认并在配置问题里提示；`README.md` 的快速开始、功能列表与 MCP 接入步骤，`doc/mcp.md` 的策略说明、权限与错误码、HTTP 请求示例、排障表同步更新，并补上 v1.3.0 令牌改造的验收记录。
- **回归测试**：主题侧新增 TOML 解析（点号 / 嵌套颜色键、语法表、字号与字重范围）、好坏主题文件并存扫描、Zed 主题转换与可载入性、组件库 `ThemeConfig` 形状兼容、扩展主题实际生效与切回内置恢复、内置语法主题不给源码加斜体等用例；MCP 侧新增本地可信身份绕过默认全隐藏权限树、强制令牌下 `UNAUTHORIZED`、HTTP 两种策略的 `401` / 放行、错令牌不降级、CLI 参数与环境变量优先级、配置项往返等用例。
