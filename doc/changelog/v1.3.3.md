# 墨笺 1.3.3

## 新增

- **安装前检测正在运行的墨笺**：安装包启动时检查 `md-work.exe` / `md-work-cli.exe` 是否仍在运行，弹窗询问是否结束这些进程后继续安装；选择「否」退出安装，选择「是」结束进程后再装。`/S` 静默安装无人应答，直接结束进程，保证无人值守安装能完成。
- **HTML 子集支持 `font-weight`**：`div` / `span` 的 `style` 属性与 `<style>` 规则可接受 `normal`、`bold` 以及 100–900 的整数，预览与 PDF / PNG 导出共用同一份字重（导出时就近映射到 Typst 字重档位）。`lighter` / `bolder` 依赖继承值，受控子集里明确忽略。
- **标题栏新增 HTML 子集文档按钮**：「导入 zip」右侧增加 `{}` 图标按钮，悬浮提示「Markdown 增强与 HTML 子集」，点击以只读预览模式打开随包部署的规范文档，复用欢迎使用 / 版本说明的编译期内置、SHA-256 校验与官方标签机制。
- **预览模式支持 Ctrl+C**：选中文字后按 `Ctrl+C` 复制渲染后的纯文本，与 Zed 行为一致；「复制为 Markdown」仍只在右键菜单里，不占用快捷键。编辑态与弹窗输入框继续使用系统默认复制。
- **笔记树定位当前打开的笔记**：左侧面板顶部增加准星按钮，一键展开祖先目录、把当前笔记滚回视口并短暂高亮；当前笔记行同时增加左侧主题色竖条、图标着色与更醒目的字重，长列表中一眼可辨。

## 优化

- **定位行为更克制**：打开笔记、切换标签等被动定位不再强制把当前笔记居中，也不在笔记树手势期间重排；显式「定位当前打开的笔记」按钮只在笔记确实滚出视口时才滚动，已在视口内则保持原样，仅闪一次背景便于发现。
- **欢迎使用文档重写**：从简短指引扩充为特性介绍，说明轻量、本地文件、AI / MCP、导出与开源等优势，补充快速上手、快捷键、数据位置与常见问题，便于新用户判断墨笺是否适合自己。
- **HTML 子集文档补全**：`doc/墨笺-html-子集.md` 补齐标签与属性表、CSS 白名单、优先级、安全边界及多个完整示例（文字上色加粗、class 提示框、图片尺寸覆盖、整篇笔记示例），并作为第四份官方文档随便携包和安装包部署，安装版设为只读。

## 修复

- **笔记树展开 / 收起不再被强行翻回去**：修复编辑状态下展开其他文件夹或笔记本时，节点刚展开就被瞬间收起的问题。原因有两处：箭头按下与抬起之间若列表因自动定位滚动，抬起时的点击会落到已变化的行上执行第二次切换；后台目录刷新又用启动时的展开快照重建行，覆盖用户刚点的状态。现在整次箭头手势只对应一次切换，后台刷新在应用时读取最新展开状态。

## 其他

- **随包官方文档扩充为四份**：`xtask package`、NSIS 安装脚本与安装包构建校验脚本同步纳入 `墨笺-html-子集.md`；安装目录中的四份文档均设为只读，zip 条目也带只读位。
- **文案**：新增 `sidebar.locate_active`、`title.html_subset`、`official_docs.html_subset_title` 中英文文案。
- **回归测试**：新增字重解析与 CSS 优先级、视口内行判断与手势超时等用例。本地验证 `cargo test -p md-work-gui --bin md-work`（62 项）、`cargo test --workspace` 全部通过，NSIS 安装脚本编译通过。
