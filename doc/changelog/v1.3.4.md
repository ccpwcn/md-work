# 墨笺 1.3.4

## 新增

- **MCP 审计列表显示调用客户端**：审计卡片新增一行客户端信息，取 MCP 握手上报的 `clientInfo`（客户端名称与版本），未上报或为空时显示「客户端未上报」。仅展示审计记录中已有的 `client` 字段，审计写入规则不变（仍不记录笔记正文）。

## 修复

- **预览模式 `Ctrl+C` 恢复可用**：v1.3.3 加入的「选中文字后 `Ctrl+C` 复制」在切换到预览模式或打开官方只读文档后可能不生效——GPUI 按键动作只沿焦点链分发，而预览根此前没有挂载焦点句柄。现在预览根挂载专用焦点句柄，切换预览模式、打开笔记或官方文档后按当前模式把焦点交给预览根或编辑器；选中预览文字后 `Ctrl+C` 可稳定复制纯文本，「复制为 Markdown」仍只在右键菜单，编辑态与弹窗输入框行为不变。

## 其他

- **文案**：新增 `mcp.audit_client`、`mcp.audit_client_unknown` 中英文文案，用于审计卡片的客户端信息行。
- **回归测试**：新增预览选区 `Ctrl+C` 用例：模拟鼠标拖选预览文字并按键，校验剪贴板包含选中文本，覆盖预览根挂载焦点后的完整动作分发链路。本地验证 `cargo test -p md-work-gui --bin md-work`（63 项）全部通过。
