# 墨笺 1.3.5

## 新增

- **「最近的笔记」面板（`Ctrl+E`）**：标题栏新增入口按钮，按 `Ctrl+E` 打开面板；左栏按笔记本切换，右栏展示最近浏览的笔记，支持关键字筛选，并可切换「最近浏览 / 最近修改 / 最近创建」三种排序。支持方向键选择、回车打开（文件夹则展开并定位），`Esc` 关闭；历史随工作区会话持久化（上限 200 条），仅记录笔记所在笔记本与相对路径。
- **笔记树右键「MCP 授权」快捷菜单**：笔记本与笔记 / 文件夹行右键新增二级菜单，可直接设为隐藏、读取、修改或删除四级授权，并显示当前等级；「打开权限设置...」可跳转到设置中的 MCP 权限页。快捷授权写入与设置面板相同的权限文件并重建签名，不依赖设置面板是否已打开。
- **设置 → 关于新增「运行时信息」**：展示软件版本、Git 提交、操作系统与系统架构，点击「复制运行时信息」一键复制稳定的英文文本（便于跨语言反馈定位）；同时提供「查看崩溃日志」按钮直接打开崩溃日志目录。原本只展示提交哈希的卡片被替换为该卡片。
- **GitHub Bug 反馈模板**：新增 `.github/ISSUE_TEMPLATE/bug_report.yml`，要求填写复现步骤、预期结果并粘贴从「运行时信息」复制的内容，崩溃日志 / 截图可选填。
- **预览复制按钮改为下拉菜单**：工具栏预览模式的「复制」按钮现在提供「复制纯文本」与「复制为 Markdown」两个选项，与预览区右键菜单行为一致：有选中内容时复制选区，无选中时复制全文。
- **MCP 路径跟随改名**：笔记或文件夹改名时记录轻量改名日志（`renames.toml`，最多 300 条）。MCP 工具仍使用 Agent 上下文中的旧路径时，若旧路径已不存在且日志能命中，则自动跟随到新路径（文件夹改名同时映射子路径），避免写工具在旧路径新建空笔记、表现为「旧名称 + No Content」。

## 优化

- **弹窗焦点收拢**：主界面与命令面板、最近的笔记、设置、导出、ZIP 导入、图片清理、崩溃恢复、输入提示、移动选择器、删除 / 工作区确认、官方只读文档等浮层分别挂载焦点陷阱，打开后 `Tab` 只在当前面板内循环，不再跑到背后的编辑器；打开浮层时主动把焦点交给它。
- **异步任务结果按版本丢弃**：预览中的公式与图片加载、导出对话框的导出任务记录当前文档 / 对话框代号，后台结果返回时若文档已切换或对话框已重开则直接丢弃，避免旧结果覆盖新状态。
- **保存与切换前等待落盘**：切换工作区、ZIP 导入前先排空写盘队列，避免把尚未写入的笔记读成旧内容；未保存标记只有真正写盘成功才推进快照，写盘失败时保留旧快照供重试，MCP 在失败窗口内仍按「可能未保存」处理，防止覆盖编辑器缓冲。
- **预览与导出的图片解析统一**：相对图片路径同时尝试笔记所在目录与笔记本根目录，并做根目录边界校验，笔记本外的文件不会被带入预览或 PDF 产物；绝对路径与越界路径不再被接受。
- **代码格式统一**：执行 `cargo fmt --all`，工作区 Rust 代码格式达到 CI 门禁要求。

## 修复

- **数据一致性**：短 GB18030 中文笔记中的中文图片名不再被误判为未引用而清理；回收站删除 / 恢复与 ZIP 合并导入的 KeepBoth 冲突改名现在会随条目迁移书签与编码提示；崩溃快照哈希仅按平台做大小写折叠，避免仅大小写不同的两份笔记互相覆盖。
- **配置迁移**：升级只写出部分 TOML 时仍读取旧 `config.json` 补齐，不再整体丢弃旧设置；损坏的 TOML 备份为 `.corrupt` 后回退到旧 JSON，而不是直接报错退出。
- **MCP 鉴权与审计**：令牌读改写统一加锁并原子落盘，消除并发吊销被覆盖的竞态；长连接会话按权限文件指纹热重载，撤销即时生效，权限文件被篡改时一律拒绝并写审计；`notebook_info` 的笔记 / 文件夹 / 字节统计只计入令牌可见的笔记，避免通过计数推断隐藏内容；本地 HTTP 服务校验回环 `Host` 与 `Origin`，防止跨站请求；审计中的搜索词改为 `sha256:<摘要>:len<字符数>`，不再明文落盘，并发追加写串行化；未保存标记文件无法读取时拒绝外部写入。
- **MCP 权限迁移**：节点移动 / 改名时保留目标路径已有的显式授权，重叠授权取更严格的等级，避免迁移导致提权。
- **导出子进程**：`wait()` 移到锁外执行，GUI 的进度轮询与取消不再被阻塞；跳过非法 UTF-8 的事件行，避免整条导出状态流中断；导出请求统一 `validate()`，在子进程入口校验输出扩展名、纸张尺寸、边距、字号、行距、图片宽度与 DPI；输出文件改用原子替换，失败时不再先删旧文件。
- **渲染与平台**：HTML 子集同级 `<div>` 不再被错误合并；打印宽度估算把中文按双字符宽度计算，避免过早换行；`.md` 右键「用墨笺打开」Verb 被删后能被自检发现并重注册；单实例管道忙时等待并重试，快速双击文件不再误开第二个窗口。
- **搜索与崩溃上报**：不区分大小写搜索中 `İ` 等字符展开后的列号改为按原文字节映射计算；崩溃上报限制 API 地址白名单、校验仓库名，并对公开 issue 的堆栈与消息脱敏、去除构建机绝对路径。
- **稳定性**：多处 `lock().unwrap()` 改为锁中毒后恢复，命令面板回车改为在输入事件结束后再重入窗口，避免双重借用崩溃。
