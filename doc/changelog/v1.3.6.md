# 墨笺 1.3.6

## 优化

- **「最近的笔记」面板改为单栏列表**：移除左栏笔记本切换，跨笔记本统一按右上角所选依据倒序展示；条目显示「笔记本/文件夹/笔记」全名（笔记省略 `.md`），上下键在单栏内循环选择。「最近浏览」只列出真正打开过的笔记，以记录时间为主、同秒内的打开顺序为辅排序；首帧最多绘制 80 行，更多结果可用关键字过滤定位，避免 Debug 构建下打开面板卡顿；无浏览记录时给出专门提示。
- **MCP 服务启停不阻塞界面**：「设置 → MCP」开关、令牌策略切换以及「应用」触发的启停改为后台线程执行；点击后立即显示「正在启动 / 正在停止本地 MCP 服务…」，完成后再显示端口或错误信息，快速反复切换时用代号丢弃过期回调，避免旧结果覆盖新状态。
- **状态栏 MCP 状态补充悬停说明**：明确该状态仅表示墨笺拉起的 `md-work-cli.exe` HTTP 服务是否存活、为只读指示，开关在「设置 → MCP」，AI 客户端自行拉起的 stdio 会话不受影响；异常状态仍以红色标识。
- **预览工具栏「复制」语义明确**：下拉项改为「复制全文」与「复制全文为 Markdown」，不再尝试读取窗口选区（点击工具栏按钮时选区已被清空）；复制选区继续使用预览区右键菜单或 `Ctrl+C`。按钮新增悬停提示。

## 修复

- **浮层关闭后焦点悬空**：打开「最近的笔记」面板或设置面板时记录原焦点，取消面板（`Esc` / 点击遮罩 / 再次 `Ctrl+E`）与关闭设置后恢复；选中笔记打开时由打开流程接管焦点，不再出现编辑区无光标、`Ctrl+E` 等快捷键失灵。
- **重复打开已打开的标签页不记入历史**：从笔记树或最近面板再次点开已打开的标签页时也会记录浏览，避免历史列表一直为空。

## 其他

- **文案**：新增 `status.mcp.tip.*`、`mcp.starting`、`mcp.stopping`、`preview.copy_all_markdown`、`preview.copy_hint`、`recent.no_history` 中英文文案。
