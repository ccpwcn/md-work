### 4.1 必须修复（Must fix）

#### CR-001 严格 clippy 基线失败，125 条同源 `result_large_err` — `crates/mdwork-core/src/lib.rs:68`（修复前行号）
- **级别**：必须修复
- **依据**：`clippy::result_large_err`；`rust-best-practices` §2「Run these and fix everything they report」；`rust-review` §2
- **问题**：`Error::Toml { path: PathBuf, source: toml::de::Error }` 最大变体 ≥128 字节，导致 `mdwork-core` 几乎所有 `Result` 的 `Err` 分支过大，工作区 `cargo clippy --workspace --all-targets -- -D warnings` 直接失败（145 条告警）。同批还有 `map_entry`、`collapsible_if`、`derivable_impls`、`unnecessary_sort_by`、`manual_map`、`err_expect`、`bool_comparison`、`len_zero` 等 20 条。
- **影响范围**：`mdwork-core`、`mdwork-render`、`mdwork-export`、`apps/gui` 全部 crate 的静态检查门禁。
- **建议修复**：
```rust
// crates/mdwork-core/src/lib.rs
source: Box<toml::de::Error>,
// crates/mdwork-core/src/toml_io.rs（2 处）
source: Box::new(source),
```
- **状态**：已修复

#### CR-002 18 处 `unsafe` 缺少 `// SAFETY:`，1 处 `unsafe fn` 缺少 `# Safety` — 多文件
- **级别**：必须修复
- **依据**：`rust-review` §3「Undefined behavior: an `unsafe` block without a `// SAFETY:` comment」；`rust-best-practices` §8
- **问题**：Windows FFI 调用块全部没有说明指针/句柄/缓冲区长度的约束，审核者无法判断前置条件是否成立。`unsafe fn print_with_dc` 也缺少 `# Safety` 文档。位置：`apps/gui/src/file_assoc.rs:17,119`、`install_hint.rs:10`、`print.rs:47,59,60,68,78,79`、`single_instance.rs:37,53,57,67`、`app/util.rs:526`；`crates/mdwork-core/src/atomic.rs:46`、`crates/mdwork-mcp/src/auth.rs:170,192`、`process.rs:12`（均为修复前行号）。
- **影响范围**：注册表读写、打印、单实例管道、DPAPI 凭据保护、原子替换等平台相关路径。
- **建议修复**：
```rust
// apps/gui/src/print.rs
/// # Safety
/// `hdc` 必须是有效、且在本次调用期间保持存活的打印机设备上下文。
unsafe fn print_with_dc(...) { ... }
// 每个 unsafe 块前补充：// SAFETY: <句柄/缓冲区/生命周期约束>
```
- **状态**：已修复（18/18 处已补齐；另将 `apps/gui/src/app/export.rs:96` 的无理由 `#[allow]` 改为带 `reason` 的 `#[expect]`）
