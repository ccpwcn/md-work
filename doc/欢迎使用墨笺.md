# 欢迎使用墨笺

墨笺（MoJiān）是一个 **Windows 上的本地 Markdown 笔记本**。它用 Rust 从零写成，笔记就是你磁盘上的普通 `.md` 文件——随时可以备份、复制、用别的软件打开，也可以交给 AI 阅读和处理。

这不是又一个「把网页套个壳」的编辑器。墨笺关心的三件事是：**写得快、文件属于你、能接进 AI 工作流**。

## 为什么选择墨笺

### 轻，真的轻

- 启动后内存占用通常在 **100 MB 以下**，大约是同类 Electron 软件的五分之一到十分之一。
- 界面用 GPUI 原生绘制，不用Chromium，不为了一个输入框启动整个浏览器。
- 约 50 MB 的大文档可在 **2 秒内**打开；同文档导出 PDF 约 5 秒。

### 文件是你的，不是软件的

- 工作区就是磁盘上的一个普通文件夹，**没有私有数据库**。删除墨笺，笔记仍在。
- 每个笔记本是一个文件夹，笔记按目录树保存；重命名、移动、复制都能在资源管理器里直接完成。
- 自动识别 UTF-8 / GBK 等编码与 CRLF / LF，按原编码保存，不会因为「中文乱码」折腾半天。

### 为 AI 时代准备

- 内置 **MCP 服务**（stdio 与仅本机的 HTTP），把工作区、笔记本和笔记安全地接入 AI 客户端。
- 默认无需令牌即可本机连接；需要按笔记本 / 笔记限权时，再开启令牌、四级权限树与审计日志（不记录笔记正文）。
- AI 产出的 Markdown 可以直接拖进墨笺归档，预览与 PDF 导出保持同一套渲染语义。

### 基础能力齐全，不做花架子

- 编辑 / 预览双模式、大纲、跨笔记全文搜索、书签、回收站、字数统计。
- Typst 渲染 PDF / PNG，页边距、字号、行高、目录深度、表格宽度都能调。
- 整本笔记本导出 / 导入 zip，导入前可预演冲突；崩溃恢复会保住没来得及保存的内容。
- 面板可自由停靠左右两侧、折叠收起；主题、字体、图床都在设置里，保持默认也完全够用。

### 开源、免费、持续修坑

墨笺采用 MIT 许可，基础功能永久免费。资源管理器双击崩溃、意外空行、emoji 失色这类老问题，这里从设计上就刻意避开。

## 五分钟上手

1. **确认工作区**：标题栏左上角选择或新建一个文件夹，例如 `D:\笔记`。工作区只放笔记，不会动系统目录。
2. **建笔记本和笔记**：左侧「笔记」面板点 `+` 新建笔记本，选中后点行尾的 `+` 新建笔记。
3. **开始写**：支持常规 Markdown 语法；写错了可以 `Ctrl+Z`，满意的笔记 `Ctrl+S` 保存（也可以开自动保存）。
4. **看效果**：`Ctrl+T` 切换编辑 / 预览。预览里选中文字按 `Ctrl+C` 复制纯文本，右键还可「复制为 Markdown」。
5. **放大招**：`Ctrl+Shift+P` 打开命令面板，模糊搜索所有功能，不用记菜单位置。

### 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+N` | 新建笔记 |
| `Ctrl+T` | 编辑 / 预览切换 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+K` | 加粗 / 斜体 / 插入链接 |
| `Ctrl+Shift+V` | 粘贴纯文本 |
| `Ctrl+Shift+P` | 命令面板 |

## 几个值得一试的功能

- **定位打开的笔记**：笔记很多时，点击左侧面板顶部的定位按钮（准星图标），树会自动展开、滚动到当前笔记并短暂高亮。
- **随包官方文档**：标题栏的 `{}` 按钮打开「Markdown 增强与 HTML 子集」说明，告诉你如何在 Markdown 里安全地使用图片尺寸、颜色、背景、字号和字重。
- **预览即所见即所得导出**：预览和 PDF / PNG 共用同一套渲染结果，屏幕上看到的排版就是导出得到的排版。
- **图片就近存放**：粘贴或拖入的图片会放进笔记本的 `assets/`，笔记搬家时图片跟着走。
- **一切皆可离线**：没有账号、没有云同步、没有遥测；断网时功能完全不受影响。

## 你的数据在哪里

| 内容 | 位置 |
| --- | --- |
| 笔记与笔记本 | 你选择的工作区文件夹 |
| 设置与上次打开的位置 | `%LOCALAPPDATA%\md-work\config\` |
| 日志、崩溃记录、恢复快照 | `%LOCALAPPDATA%\md-work\` |
| 安装目录 | `%LOCALAPPDATA%\Programs\md-work` |

安装包只写当前用户目录和 HKCU，不需要管理员权限，也不会悄悄抢走 `.md` 文件的默认打开方式。

## 遇到问题

- 右上角铃铛是通知中心，保存失败、文档校验提示等都会汇总在这里。
- 设置页可以查看 MCP 接入说明、主题字体、工作区与 Windows 文件关联。
- 崩溃时日志保存在本地；配置令牌后才会在启动时尝试上报，且不包含笔记正文。

篇幅有限，更细的说明见安装包目录里的 `mcp.md`、`墨笺-html-子集.md` 与发版说明。

现在，开始写点什么吧。
